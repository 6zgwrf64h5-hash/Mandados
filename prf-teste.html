Teste do Face ID para criptografia

Este teste só verifica se o seu iPhone consegue gerar uma chave de criptografia a partir do Face ID (extensão PRF). Nada é enviado para fora: tudo roda aqui no aparelho. Ele cria uma chave de teste no seu chaveiro (passkey) chamada "Mandados teste"; pode apagá-la depois em Ajustes, Senhas.

Abra esta página no Safari, toque em "Rodar o teste" e confirme o Face ID quando o iPhone pedir (duas ou três vezes).
